ANALYST HUB — EDITABLE WEBSITE WITH LOGO

1. Keep index.html, style.css, analyst-hub-logo.png and favicon.png together.
2. Open index.html in a browser to preview.
3. Edit wording in index.html; edit colors and layout in style.css.
4. To change the logo, replace analyst-hub-logo.png with a new PNG using the same filename.
5. The logo appears in the top-left navigation bar.
