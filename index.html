02 Workplace Policies & Tools

Security: Access only authorized datasets. Never store confidential customer information on personal devices or share it outside approved systems.

File management: Preserve original datasets; save working files in approved shared folders using consistent names, such as Sales_Report_2026_10_v1.xlsx .

Quality assurance: Verify calculations, document assumptions, and review outputs before distribution.

04 Step-by-Step: Collect Sales Data

Goal: Retrieve one month of transactions from an authorized database.

  1. Open the approved SQL client and sign in with company credentials.
  2. Select the authorized sales database and verify table and column names.
  3. Run the sample query below, adapting it to the actual database schema.
  4. Check the returned columns, dates, and record count.
  5. Export a CSV to the approved folder; record the source, query, and extraction date. 
SELECT order_id, order_date, sales_amount
FROM sales_orders
WHERE order_date >= '2026-09-01'
  AND order_date < '2026-10-01';
Checkpoint: Confirm that the date range and record count match the request.

05 Step-by-Step: Clean & Validate

Goal: Prepare an accurate dataset without removing legitimate records.

  1. Open the CSV in Excel and save a separate working copy.
  2. Filter for missing values; flag incomplete records for investigation.
  3. Highlight duplicate transaction IDs; verify whether duplicates are errors.
  4. Standardize dates and numeric formats; inspect unusual sales amounts.
  5. Compare counts and totals against the original; document every correction.

07 FAQ & Resources

What if values are missing?

Flag the records, investigate the source, and consult the project owner before assuming replacement values.

What if my SQL query returns no results?

Check the connection, permissions, table names, filters, and date range. Escalate access problems to the database administrator.

What if totals differ from an existing report?

Compare sources, date ranges, filters, and calculation methods. Document differences before publication.

Who can help?

Contact your supervisor for priorities, the database administrator for access, and the reporting team for dashboard standards.
